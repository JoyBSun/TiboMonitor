TiboMonitor v1.1.2 - Windows x64

INSTALL
1. Extract the complete ZIP file.
2. Double-click Install.cmd.
3. TiboMonitor will be installed to:
   %LOCALAPPDATA%\Programs\TiboMonitor
4. The application starts automatically and appears in the notification area.

UPDATE
Extract a newer release and run its Install.cmd. Existing UserData is preserved.

UNINSTALL
Run Uninstall.cmd from the installed application directory.

NOTES
- No administrator rights are required.
- .NET is included; no separate runtime installation is required.
- The release is not code-signed, so Windows SmartScreen may show an
  unknown-publisher warning.
- Only download builds from the official GitHub Releases page.
